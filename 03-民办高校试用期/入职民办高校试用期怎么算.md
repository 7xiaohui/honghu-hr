> 法定红线 × 实践操作 × 避坑要点 

提到试用期，不少刚拿到民办高校offer的同学一头雾水：签几年合同、试用几个月、工资打几折、寒暑假算不算、学校说辞退就辞退？这些问题，其实《劳动合同法》早就划好了线。

这篇文章以《劳动合同法》和《劳动合同法实施条例》为基础，把通用法定规则和民办高校的行业实践放在一起讲，覆盖试用期限、薪资社保、岗前培训、考核标准、劳动关系解除五个板块，重点说试用期到底是怎么回事。

**先说一个前提：**民办高校在民政部门登记为"民办非企业单位"，依据《劳动合同法》第二条，跟教职工签劳动合同直接适用该法。这跟公办高校编制内教师走《事业单位人事管理条例》不是一回事——公办编制教师试用期可以到12个月，民办高校最长只有6个月。别搞混了。

## 第一章 试用期期限：法定红线与协商空间

### 1.1 法律强制规定（全行业统一，没得商量）

试用期长短跟合同期限直接挂钩，这是《劳动合同法》第十九条定的硬规矩，任何行业都一样：

| 劳动合同期限 | 试用期上限 | 法律依据 |
| --- | --- | --- |
| 3个月 ≤ 期限 < 1年 | ≤ 1个月 | 《劳动合同法》第19条 |
| 1年 ≤ 期限 < 3年 | ≤ 2个月 | 《劳动合同法》第19条 |
| ≥ 3年 或 无固定期限 | ≤ 6个月 | 《劳动合同法》第19条 |
| 不满3个月 / 以完成任务为期限 | 不得约定 | 第19条第3款 |
| 非全日制用工 | 不得约定 | 第70条 |

还有两条铁律：同一单位同一员工只能约定1次试用期，调岗、升职、续签都不能再来一次；试用期必须包含在劳动合同期限内，单独签"试用期合同"是无效的，那段日子直接算正式合同期。

**违法代价：**用人单位超期约定试用期的，依据《劳动合同法》第83条，不仅要改正，已经履行的超期部分还得按转正工资标准向劳动者支付赔偿金。试用期拖得越长，赔得越多——这条是劳动者维权最直接的武器。

### 1.2 哪些可以商量，哪些单位能自主定

法定上限是天花板，双方可以书面约定更短的试用期，但绝不能往上突破。

试用期变通这块要分清两件事：如果是因为劳动者自己请了长期病假、事假、停工待岗，双方可以书面约定试用期顺延，但法定节假日和正常休息日不能顺延。但用人单位单方延长试用期，或者拿"考核还没做完"当理由拖延——司法实践中大概率会被认定为二次约定试用期，直接撞上第83条赔偿金。

**一句话总结：**试用期到期那天，学校必须给出明确判断——合格还是不合格。不能用任何理由无限期搁着。

### 1.3 高校的特殊问题：寒暑假怎么算？

寒暑假是教育行业特有的周期性休假，法律并没有把它从试用期里排除。试用期是连续计算的，寒暑假默认计入试用期时长，学校不能拿放寒暑假当理由把试用期拉长。

但考虑到行业实际，不同岗位确实有差异：

**专任教师岗：**如果试用期正好横跨寒暑假，没有授课任务也没法考核，学校可以书面约定把考核周期顺延到正常授课的学期。但这里有个关键问题必须说清楚——考核周期顺延 ≠ 试用期顺延。考核周期顺延，延后的是"考核时间"，不是"试用期结束时间"，更不是"转正工资的起算时间"。

**暑假期间工资按什么标准发？**  
  
举个例子：合同约定试用期3个月（4月1日至6月30日），7-8月放暑假，考核顺延到9月开学。6月30日试用期到期那天，学校必须给出结论——要么有充分证据证明不合格、在试用期内辞退；要么拿不出证据，法律上就视为符合录用条件，自动转正。试用期一到期，不存在"考核没做完所以继续发试用期工资"的中间状态。7-8月的工资按转正后的全额标准发放，不是80%。  
  
说白了，学校想通过考核周期顺延来在暑假继续发80%的试用期工资——这个出发点在法律上站不住。考核早一点晚一点确实无所谓，实践中多数也能提前完成，但试用期到期日是死的，到期就得给结论。

**协商延长试用期，风险极高：**实践中确有表现不达标时双方书面协商延长试用期的做法——延长后继续考核，再不达标就不再聘用。但同一用人单位与同一劳动者只能约定1次试用期，延长试用期即便双方签字同意，司法实践中仍可能被认定为"二次约定试用期"而构成违法，直接撞上第83条赔偿金。更稳妥的做法是在法定试用期内完成考核，到期时基于已有证据作判断——合格转正，不合格辞退，不拖泥带水。

**辅导员岗、行政管理岗：**寒暑假正常值班办公，试用期照常计时，不能顺延。

## 第二章 薪资、社保、岗前培训：底线在哪，哪些能谈

### 2.1 试用期工资标准

依据《劳动合同法》第20条和《劳动合同法实施条例》第15条，试用期工资有三条底线，必须同时满足：

80%不低于本单位相同岗位  
最低档工资的80%

80%不低于劳动合同  
约定工资的80%

最低不低于用人单位  
所在地最低工资标准

三条线取最高值执行，任何一条达不到就算违法。

### 2.2 社保缴纳

依据《社会保险法》，建立劳动关系之日起30日内，单位必须依法缴纳五险。"自愿放弃社保""转正再补缴"这些操作都是违法的——就算劳动者签了放弃协议，因为违反法律强制性规定，协议也是无效的，单位照样得补缴，还可能搭上滞纳金。

**遇到不交社保怎么办？**可以直接向当地社保经办机构或劳动监察部门投诉举报，不用走劳动仲裁。

住房公积金依据《住房公积金管理条例》也属于法定缴纳范围，但它跟社保不一样：公积金争议不归劳动仲裁管，劳动者得向当地住房公积金管理中心投诉举报。

### 2.3 岗前培训算不算试用期？

签了合同之后的师德培训、教学岗前集训、岗位实训，全部计入试用期时长，而且必须带薪，工资同样遵守80%底线。但签合同之前的宣讲、体验课不算用工，不计试用期、也不发工资。也就是说，入职培训之日起应该视为劳动关系建立，只不过不是说一建立关系立马就干活，培训也是劳动的前提，也是内容的一部分。

试用期内，如果学校出资送你去专项技术深造，可以依据《劳动合同法》第22条签服务期协议、约定违约金。但有个实务中的坑要注意：你在试用期内按第37条提前3天通知就能走人，这跟服务期违约金之间是有冲突的，签之前想清楚。

## 第三章 试用期考核：法律要求与三类岗位实操

### 3.1 考核的通用法律底线

录用条件必须白纸黑字写清楚，载入合同或岗位说明书，口头说的不算数，但多数单位实际上没有这个意识，实践中发岗位说明或者员工手册的很少。

更重要的是，法院和仲裁机构已经形成了稳定的裁判规则——学校想以"不符合录用条件"辞退试用期员工，必须同时过三道关：

1有具体、明确、  
可量化的录用条件

2已通过合同/岗位说明书  
向劳动者公示告知

3有充分证据证明  
劳动者未达标

三道关缺一道，就是违法解除，依据《劳动合同法》第87条得按经济补偿标准的2倍赔钱。

**对应聘者说：**如果你的合同和岗位说明书里没写具体录用条件，且单位没有充分证据证明自己不适合岗位的，通常法院或仲裁机构不会支持。

### 3.2 三类岗位考核各有侧重

**专任教师岗**考核量化最严格，主要看教案课件、课堂授课质量、学生评教、教研任务完成情况、师德师风。考核周期跟着学期走，寒暑假只看备课，正式考核集中在有课的学期。一句话，要站稳讲台。

**辅导员岗**可量化的指标不多，考核以班会组织、学生日常管理、应急处理、家校沟通这些定性内容为主。

**行政、管理岗**考核侧重事务办结效率、台账整理、部门协调，弹性最大。

## 第四章 试用期解除：离职与辞退的规则

### 4.1 劳动者主动离职

依据《劳动合同法》第37条，试用期员工提前3日通知用人单位就能走，不需要单位审批同意，工资该结多少结多少。

关于违约金：第25条规定，除了第22条专项培训服务期、第23条竞业限制这两种情况外，单位不能跟劳动者约定由劳动者承担违约金。所以普通岗位试用期离职，不用赔钱。

### 4.2 用人单位合法辞退条件

单位试用期解除合同，必须说明理由，而且只能基于以下几种情形：

1. 不符合录用条件 无需补偿

   最常用的辞退理由。学校必须有充分证据证明你不符合事前书面约定的录用条件，不需要提前通知，也不需要支付经济补偿。但前提是"三道关"全过。
2. 严重违纪 / 严重失职 无需补偿

   员工严重违反规章制度，或师德师风问题给单位造成重大恶劣影响，可以立即解除合同，无需补偿。
3. 多重用工影响本职 无需补偿

   同时与其他单位建立劳动关系，对本职工作造成严重影响，或经提出拒不改正的，可解除合同。
4. 医疗期满不能胜任 需提前通知+补偿

   患病或非因工负伤，医疗期满后不能从事原工作，也不能从事另行安排的工作。学校须提前30日书面通知或额外支付1个月工资，并依法支付经济补偿。

   法律依据：第40条第1项
5. 不能胜任工作 需提前通知+补偿

   不能胜任工作，经过培训或调岗后仍不能胜任。同样须提前30日书面通知或额外支付1个月工资，并支付经济补偿。

   法律依据：第40条第2项

**关键区别：**"不符合录用条件"和"不能胜任工作"是两条完全不同的路。前者不用赔钱，后者必须走培训/调岗流程还要给补偿。

## 写在最后

试用期的时间长短、薪资社保、考核标准，法律都划了明确的线。拿到offer的同学不妨对照法条逐条看一看：合同期限对不对、试用期有没有超、工资够不够底线、社保有没有按时交——心里有数，遇到问题才不慌。

该争取的权益要争，但该努力的也要努力。试用期是双向考察，学校在看你的表现，你也在看这份工作适不适合自己。别因为"提前3天就能走"就把离职当成随便的事——每一次换工作都有成本，想清楚再动。
