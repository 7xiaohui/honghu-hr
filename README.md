## 这是什么

2026 年，我在公众号上写过三篇长文，主题都落在“毕业生从学校到单位”的那段路上：

- 三方协议怎么签、怎么毁、和劳动合同什么关系；
- 人事档案去哪、怎么转、哪些操作会变成“死档”；
- 入职民办高校，试用期到底怎么算。

另外还有一份《民办高校应聘简历投递指南》，讲材料清单、简历要素、辅导员/管理岗差异和邮件投递。

这些内容大多来自**高校人事的实际经办**，不是网上常见的泛泛建议。原稿已经丢了，这里是从公众号原文导出、重新整理的存档。

## 适合谁

- 应届/往届毕业生，准备签三方、转档案、入职高校；
- 想进民办高校的专任教师、辅导员、管理岗位；
- 高校人事/辅导员，需要给学生讲清楚流程的人；
