## 为什么按 01/02/03/04 编号

之前分成 `articles/` 和 `guides/`，是按**文件类型**分的：
文章放一处，PDF 放一处。

但你的实际使用方式是**一套连续的素材**，不是“文章库 + 附件库”。
所以现在改成**按编号的主题文件夹**：

- 一个编号 = 一个主题；
- 以后新增，直接 `05-…`、`06-…` 往下排；
- 每个主题里可以放 Markdown、PDF、图片、附件，不再按文件类型拆。

**编号是“资产编号”，不是“阅读顺序”。**

---

## 推荐阅读顺序

如果是第一次看，建议按实际办事顺序读：

> **04 简历投递 → 01 三方协议 → 02 人事档案 → 03 试用期**

- 先投简历、拿 offer；
- 再签三方；
- 毕业前转档案；
- 入职后看试用期。

编号 01–03 是文章写作/发布顺序，04 是后补的简历指南；不用被编号绑架。
