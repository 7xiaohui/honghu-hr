## 0. 先看三句话

1. **先看公告，再准备材料。** 学校给了官方模板/清单的，一律以学校为准；这份指南是通用底稿，不是替代公告。
2. **材料完整、命名清楚、能打开**，比“简历写得多漂亮”更重要。人事初审每天看大量邮件，先被刷掉的往往是缺件、命名乱、附件打不开。
3. **时间线不能断。** 学历、工作经历从高中/上一段工作到现在的每一段都要连续；有间隔就如实说明，不要留空白。

## 1. 投递材料清单与附件要求

民办高校（专任教师、辅导员、管理人员）各校要求略有差异，但核心附件基本一致。下面按优先级排列。

| # | 材料 | 具体要求 | 是否必须 |
|---|---|---|---|
| 1 | 个人简历 | 按学校模板或自备模板，含基本信息、学历、工作经历、科研成果等（详见第 3 节） | 必须 |
| 2 | 身份证扫描件 | 正反面扫描在同一页 | 必须 |
| 3 | 学历学位证明 | 第一学历至最高学历的毕业证、学位证扫描件；学信网有效期内的《学历证书电子注册备案表》或《中国高等教育学位在线验证报告》 | 必须 |
| 4 | 各阶段成绩单 | 第一学历至最高学历，本科/硕士/博士各阶段成绩单扫描件 | 必须 |
| 5 | 职称证书 | 职称证扫描件 + 职称系统查询页面截图；省内职称按各省人社厅查询路径截图，省外职称提供当地查询截图 | 如有则提供 |
| 6 | 高校教师资格证 | 扫描件；应届毕业生未取得的，可暂不提供 | 如有则提供 |
| 7 | 其他资格证书 | 普通话等级证、英语四六级证、计算机等级证、技能证书等 | 如有则提供 |
| 8 | 教科研成果材料 | 论文（封面—版权页—目录—正文—检索页）、专著（封面—版权页—目录—CIP 检索页）、项目（立项/结项证书）、奖励（荣誉证书）、专利（授权证书） | 如有则提供 |
| 9 | 工作经历证明 | 有工作经历者：上家单位劳动合同、考核结果、离职证明、职称评审等材料；以招聘单位要求为准，至少提供离职证明 | 有工作经历必须 |

### 1.1 附件命名与合并

多数高校要求把扫描件按顺序合并成一个 PDF。常见命名格式：

```text
应聘岗位---姓名---职称---最高学历---毕业院校---专业---手机号
```

示例：

```text
专任教师---张三---讲师---硕士---XX大学---计算机科学与技术---18888888888
```

如果公告没有明确命名要求，建议统一为：

```text
姓名+应聘岗位+学历+专业+手机号.pdf
```

### 1.2 扫描与大小

- 扫描件清晰，建议 300dpi 以上彩色扫描；
- 每份证书单独扫描一页，不要把正反面拼到不同页；
- 合并 PDF 时按清单顺序排列，方便审核人员对照；
- 总大小控制在 20MB 以内；超出时压缩图片质量，或按公告要求分卷。

## 2. 特殊情况：暂时无法提供的材料

| 情况 | 替代方案 | 说明 |
|---|---|---|
| 应届生尚未取得最高学历学位证 | 学信网学历注册备案表 + 学籍在线验证报告，或学生证扫描件 | 入职后补交毕业证、学位证 |
| 境外取得的学历 | 毕业证书原件 + 教育部留学服务中心认证件 | 未经认证的境外学历一般不予认可 |
| 未取得职称证 | 可不提供 | 非硬性门槛，有则加分 |
| 未取得高校教师资格证 | 可暂不提供 | 部分高校要求入职后限期取得 |
| 省外职称证查询 | 按发证省份人社厅查询路径截图 | 省内职称按本省人社厅路径截图 |
| 上家单位离职证明尚未拿到 | 离职申请批复截图/邮件 + 书面说明 | 入职前补交正式离职证明原件 |
| 上家单位合同/考核材料遗失 | 社保缴纳记录证明工作经历 + 书面说明 | 社保记录可在当地人社 APP 或政务服务网下载 |
| 成绩单遗失 | 联系毕业院校教务处/档案馆补办或开具证明 | 部分学校支持线上申请邮寄 |

**关键提醒：**

有工作经历的应聘者，务必准备上家单位的**劳动合同 + 考核结果 + 离职证明**三件套。即使投递时没有全部提供，入职审核时通常还会再要。高校人事会核查工作经历的连续性，缺件可能影响录用审批；确实无法提供的，提前和招聘方人事处沟通说明原因。

## 3. 简历核心要素：六个模块

综合多所民办高校的应聘登记表和简历模板，格式各不相同，但核心要素基本一致。一份完整的简历至少包含下面六块。

### 模块一：个人基本信息

必填：姓名、性别、出生年月、民族、籍贯、政治面貌（辅导员岗位尤其重要）、婚姻状况、身份证号、联系电话（手机 + 固话）、电子邮箱、通讯地址、近期免冠证件照。

部分学校还会要求：身高体重、血型、招聘信息来源、是否有亲友在本校任职、紧急联系人、微信号等。按学校模板填写即可。

### 模块二：学历背景（从高中到博士）

| 阶段 | 需填写信息 |
|---|---|
| 高中 | 起止年月、学校名称 |
| 本科 | 起止年月、毕业院校、所学专业、学历/学位、是否全日制、学制 |
| 硕士 | 同上 + 研究方向 |
| 博士 | 同上 + 博士研究方向 |

**重点：时间不能断档。** 从高中入学到最高学历毕业，每一段经历必须连续。有间隔年、休学、考研二战等情况，在“其他须说明事项”中如实注明。

### 模块三：个人工作履历

每段工作经历包含：起止时间、工作单位、所在部门、岗位/职务、离职原因；部分高校还要求月薪和证明人电话。

**重点：工作履历同样不能断档。** 两份工作之间间隔超过 3 个月的，建议补充说明（备考、自由职业、培训进修等）。高校人事审核很看重履历的连续性和真实性。

### 模块四：教科研详细业绩

这是专任教师岗位的核心模块，直接影响评审评分。建议分类整理：

| 类别 | 需填写信息 | 佐证材料 |
|---|---|---|
| 论文 | 题目、期刊名称、发表时间、作者排名（第一/通讯/合作）、收录情况（SCI/EI/核心期刊） | 封面—版权页—目录—正文—检索页 |
| 科研课题 | 项目名称、项目编号、个人排名、级别（国家级/省部级/厅级/校级）、进展（在研/结项）、下达单位/时间 | 立项通知书/结项证书 |
| 专著/教材 | 书名、出版社、出版时间、ISBN、作者排名、字数 | 封面—版权页—目录—CIP 检索页 |
| 专利 | 专利名称、专利号、专利类型（发明/实用新型/外观设计）、授权时间、发明人排名 | 专利授权证书 |
| 奖励/荣誉 | 奖项名称、排名、级别、时间、颁发部门 | 奖励证书/荣誉证书 |

### 模块五：其他荣誉与个人评价

- 获奖情况：各级各类荣誉表彰、指导学生竞赛获奖、教学比赛获奖等；
- 资格证书：高校教师资格证、普通话等级证、外语水平证书、计算机等级证、行业职业资格证等；
- 个人评价/特长：200 字左右，突出与应聘岗位相关的优势和具体成绩（教学经验、企业实践、竞赛指导等）；
- 家庭情况：部分高校要求填写主要家庭成员（父母、配偶、子女）的姓名、政治面貌、工作单位、岗位、联系电话。

### 模块六（可选）：工作计划及打算

部分高校的报名表设有“其他须说明事项”或“入职后工作计划”栏目。建议简要写明入职后的教学规划、科研方向、学科建设思路，体现你对岗位的认真态度和专业思考，控制在 300 字以内。

### 模板使用建议

- 学校提供了官方模板：**必须用官方模板**，不要自行更换格式；
- 学校只说“提供个人简历”、没有指定模板：按上述六大模块自行制作，建议用表格呈现，条理清晰；
- 不要使用艺术照、二次元背景、花哨拼色等不严肃的版式；
- 简历控制在 2–3 页，重点信息放第一页。

## 4. 辅导员岗位补充要求

辅导员岗位在通用简历之外，通常还有额外要求。

### 4.1 额外材料

| 材料 | 说明 |
|---|---|
| 党员身份证明 | 中共党员或预备党员证明材料：所在党组织出具的党员证明信（加盖公章），或党费证/党员证扫描件；部分高校可通过全国党员管理信息系统核实 |
| 学生干部经历证明 | 大学期间担任班长、团支书、学生会干部等的证明材料（学院盖章的任职证明或聘书扫描件） |
| 学生工作相关成果 | 组织过的活动照片、获奖证书、辅导员工作案例等（如有） |
| 心理咨询类证书 | 心理咨询师证、生涯规划师证等（如有则提供，非必须） |

### 4.2 简历重心调整

- 突出学生工作经历：学生会、社团、班委任职，具体写明组织过什么活动、带过多少学生；
- 突出思想政治相关工作：党课培训、团日活动、志愿服务等组织经历；
- 教科研成果可弱化，重点放在学生管理和思政教育能力；
- 个人评价强调沟通能力、责任心、抗压能力等辅导员核心素质。

**关键提醒：** 辅导员岗位几乎都要求中共党员（含预备党员）。预备党员需提供接收预备党员的批复文件或支部证明；入党积极分子一般不符合应聘条件。

## 5. 管理岗位补充要求

管理岗位（行政、教务、人事、财务、文秘、宣传等）要根据具体岗位调整重心，不能一份简历投所有岗位。

### 5.1 常见管理岗位及简历重心

| 岗位 | 简历重心 | 建议额外提供 |
|---|---|---|
| 文秘/宣传 | 文字功底、公文写作经验、新媒体运营能力 | 已发表的文字作品（公文、新闻稿、推文）、视频作品、公众号运营截图等 |
| 教务管理 | 教务系统操作经验、教学管理经历、数据分析能力 | 教务系统操作截图/证书、教学管理相关培训证书 |
| 人事管理 | 人力资源工作经验、劳动法知识、招聘培训实操 | 人力资源管理师证、相关项目案例 |
| 财务管理 | 财务工作经历、会计核算经验、预算管理能力 | 会计从业资格证/初级会计师证等、财务软件操作能力证明 |
| 招生就业 | 市场推广经验、沟通协调能力、数据分析能力 | 招生宣传方案、市场调研报告等作品 |
| 后勤/保卫 | 后勤管理经验、安全管理经历、协调能力 | 安全管理类证书、相关管理案例 |

### 5.2 管理岗简历通用调整原则

- 把与招聘岗位最相关的工作经历放在最前面，不要被时间倒序淹没；
- 突出可迁移技能：文秘岗强调文字能力，即使不是专职文秘，写材料、做报表、做汇报的经历都算；
- 提供作品集：实际工作成果比“文字功底扎实”有说服力；
- 弱化教科研部分，管理岗不看重论文发表，把篇幅让给工作经历和能力；
- 有高校工作经历的，重点突出：高校内部经验是管理岗的重要加分项。

## 6. 邮件投递注意事项

### 6.1 邮件格式规范

| 项目 | 规范 |
|---|---|
| 邮件主题 | 必须包含：姓名 + 应聘岗位 + 学历 + 专业；有公告格式的，严格按公告 |
| 示例 | `张三-应聘专任教师-硕士-计算机科学与技术-手机号` |
| 正文 | 纯文本或简单排版，不要花哨 HTML；称呼 + 正文 + 结尾敬语，控制在 200 字以内 |
| 称呼 | 知道联系人：尊敬的 X 老师/X 主任；不知道：尊敬的 XX 学院招聘负责人 |
| 结尾 | “此致 敬礼”或“祝工作顺利”，换行署名：姓名 + 联系电话 + 日期 |
| 附件命名 | 简历：`张三-专任教师-简历.pdf`；附件：`张三-专任教师-附件材料.pdf` |
| 附件格式 | 统一 PDF；除简历外尽量不发 Word 源文件（排版可能错乱），不发图片格式简历（无法复制文字） |
| 附件大小 | 总大小控制在 20MB 以内；不要发超大附件或云盘链接 |
| 发送邮箱 | 使用常用邮箱；部分高校邮件系统会拦截企业邮箱/超大附件；邮箱名建议用真实姓名拼音 |

**不要用**“新建文档”“未命名”“简历最终版”这类附件名；附件多时压缩后上传，不要用有效期很短的“超大附件”或网盘链接。

### 6.2 发送前检查清单

- [ ] 邮件主题是否符合公告要求；
- [ ] 附件是否全部上传，逐个点开确认能打开；
- [ ] 附件命名是否规范统一；
- [ ] 正文是否写明应聘岗位、联系方式；
- [ ] 是否有错别字，尤其是学校名称、学院名称、招聘人姓名；
- [ ] 发送邮箱能否正常接收回邮（可以先给自己发一封测试）；
- [ ] 发送时间建议在工作日上午 9:00–11:00，避免周末或深夜。

### 模板二：有工作经历者投递专任教师

**邮件主题：** `王芳-应聘专任教师-讲师-硕士-汉语言文学-手机号`

```text
尊敬的 XX 学院人事处/招聘负责人：

您好！

我是王芳，现为 XX 学院汉语言文学专业讲师，具有 5 年高校教学经验。从贵校官网获悉正在招聘专任教师，特此投递。

本人硕士毕业于 XX 大学汉语言文学专业，已在高校任教 5 年，主讲《现代汉语》《大学语文》等课程，累计授课超过 1200 课时。任教期间主持校级教改项目 1 项，发表学术论文 4 篇（其中核心期刊 1 篇），获校级教学比赛二等奖 1 次。已取得高校教师资格证、普通话一级乙等证书。
```
