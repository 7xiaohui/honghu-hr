## 内容

- 投递材料清单与附件命名/合并规范；
- 特殊情况：应届未拿证、境外学历、职称/教师资格证缺失、离职证明未拿到；
- 简历六大模块：基本信息、学历、工作履历、教科研业绩、荣誉/评价、工作计划；
- 辅导员岗位补充要求（党员、学生干部经历等）；
- 管理岗位差异化要求（文秘/宣传、教务、人事、财务等）；
- 邮件格式、附件规范、发送前 7 项检查；
- 3 个邮件模板（应届专任教师、有工作经历专任教师、辅导员/管理岗）。
